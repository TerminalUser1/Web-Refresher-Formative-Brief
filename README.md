
++.2# Study Space

A single-page Web Refresher project using HTML5, CSS and JavaScript. No framework, installation or external assets are required.

## Run
Open index.html in a modern browser. Click Dark mode to change appearance. Tick the three tasks to update the completion message. Refreshing resets your choices. The 25-minute panel is a study suggestion, not a countdown timer.

## Files
- index.html: semantic structure, headings and labelled controls.
- styles.css: colours, Grid layout and responsive media queries.
- script.js: theme switching and checklist event handling.
- EXPLANATION.md: a walkthrough and testing instructions.

## Reflection 


Working on Study Space helped me understand how HTML, CSS and JavaScript work together. I found the HTML structure easier to follow because the headings and sections clearly organised the page. I also tried to use the 60–30–10 colour rule, with a main background colour, a secondary colour for panels and an accent for smaller details.

The JavaScript was harder for me to understand, especially how clicking a button or ticking a checkbox changes the page. This is an area I still need to practise.

During Web Development II, I would like to improve my JavaScript skills and become more confident with responsive layouts. I plan to build small examples and check them at different screen sizes. This project helped me recognise what I understand and where I need more practice.
